# Changesets

Add a Changeset for public behavior, metadata, contract, packaging, documentation, or migration changes after `0.1.0`. Choose the semantic impact deliberately and summarize the user-visible change. This repository is distributed through Git and host plugins rather than npm, so Changesets owns version intent while release publication remains a separate approved action.

The initial `0.1.0` release candidate is recorded directly in `CHANGELOG.md`; there is no pending Changeset for work already included in that candidate.
