# Changelog

All notable changes to Gremlin Skills are documented here. A version entry describes a release candidate; it does not imply that a Git tag, hosted release, plugin listing, or marketplace publication exists.

## 0.2.0 — 2026-08-09

- Refactored the SEO workflow so Foundation preserves evidence strength and Strategy stops at portfolio-level page opportunities instead of turning unproven observations into implementation briefs.
- Made SEO Content and Landing Page responsible for query-specific competitive benchmarking, page requirements, editorial review, and explicit `PUBLISH`, `REVISE`, `NO PAGE`, or `BLOCKED` verdicts before implementation.
- Added a shared SEO page-quality contract covering evidence classes, truth versus competitiveness, compelling and durable titles, catalogue growth, and comparative editorial judgment so technical correctness cannot rescue a weak page.
- Made Landing Page and SEO Content auto-discoverable while preserving their approval gates, and added regression coverage for unsupported competitor assumptions, Strategy overreach, brittle inventory-count titles, bland risk-avoidance copy, and technically valid but noncompetitive pages.

## 0.1.0 — 2026-08-06

- Established the canonical 36-skill registry, public skill documentation, maturity and authority metadata, and generated catalogs.
- Added approved auto-discoverable and explicit-invocation-only policies for Codex and Claude.
- Added deterministic standalone archives, flat host-specific plugin payloads, guarded repository-first synchronization, and coexistence validation.
- Added safety, artifact, quality, product, handoff, generic coexistence, public-release, and clean-snapshot validation.
- Added MIT licensing, contribution and security guidance, acknowledgements, third-party notices, and a strict public-source boundary.

This is the initial public release of the Gremlin Skills collection.
