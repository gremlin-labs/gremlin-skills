# Changelog

All notable changes to Gremlin Skills are documented here. A version entry describes a release candidate; it does not imply that a Git tag, hosted release, plugin listing, or marketplace publication exists.

## 0.1.0 — 2026-08-06

- Established the canonical 36-skill registry, public skill documentation, maturity and authority metadata, and generated catalogs.
- Added approved auto-discoverable and explicit-invocation-only policies for Codex and Claude.
- Added deterministic standalone archives, flat host-specific plugin payloads, guarded repository-first synchronization, and coexistence validation.
- Added safety, artifact, quality, product, handoff, generic coexistence, public-release, and clean-snapshot validation.
- Added MIT licensing, contribution and security guidance, acknowledgements, third-party notices, and a strict public-source boundary.

This is the initial public release of the Gremlin Skills collection.
