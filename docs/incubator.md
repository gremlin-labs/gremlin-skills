# Incubating skill ideas

These are Gremlin-native opportunities identified by the package audit. They are not installed skills, promises, or parity work. Each candidate still needs outcome discovery, routing evidence, authority design, overlap analysis, and explicit approval before implementation.

## Highest-confidence gaps

### Codebase Audit

A broad, read-only whole-codebase improvement audit for cases that do not have a reference project or a stronger specialist audit. It should prioritize structural friction, product impact, safety, and actionable Goalpro handoff material without becoming a generic implementation skill.

### Diagnose

An evidence-first debugging workflow that reproduces, minimizes, hypothesizes, instruments, fixes, and regression-tests bounded defects. It should remain narrower than Goalpro and make source-mutation authority explicit.

### Architecture Audit

A read-only owner for module boundaries, cohesion, dependency direction, and larger refactoring opportunities that exceed Restructure's filesystem and mechanical-import scope. Approved findings would hand off to Goalpro rather than letting the audit mutate source.

### Accessibility Audit

A dedicated cross-product accessibility audit covering complete journeys, keyboard and assistive-technology evidence, responsive behavior, motion preferences, content semantics, and an executable remediation handoff. It should defer to more specific implemented-flow audits when they already own the experience.

### Skill Eval

A maintainer workflow for running fresh-context routing, near-miss, authority, artifact, and safety evaluations in disposable repositories. It would operationalize the existing evaluation corpus while keeping deterministic fixture validation separate from model judgment.

## Specialist opportunities

- **Technical SEO Audit** — systemic crawl, rendering, metadata, structured-data, performance, and indexability diagnosis for mature sites; distinct from initial SEO Setup.
- **Experiment Design** — reusable event semantics, guardrails, holdouts, maturity windows, and decision rules shared across onboarding, lifecycle email, and SEO programs.
- **Email Deliverability Diagnose** — operational incident diagnosis for reputation, authentication, suppression, provider, and inbox-placement failures currently outside the lifecycle strategy skills.
- **Documentation Authoring** — implementation-grounded creation and updating of bounded API docs, guides, runbooks, and reference material; distinct from Documentation Audit's repository-wide read-only drift and governance analysis.
- **Publishpro** — a guarded post-Releasepro workflow for exact hosted releases and artifact publication. This would require strong provider-specific authority, credential, confirmation, rollback, and receipt design.

## Explicit non-candidates

Do not add interviewing, grilling, setup-wrapper, or other look-alike skills merely to mirror another catalog. New skills must close an observed Gremlin workflow gap and compose with existing ownership boundaries.
