# Motion Direction

Art-directs a TurbulenceJS-first motion language for an application, compares two or three coherent animation directions in an interactive synthetic Motion Direction Studio, and turns the approved direction into an enforceable policy for current and future pages, components, and states.

## When to reach for it

Use when the user asks to define an animation strategy, explore playful or cinematic motion styles, make a site feel more joyful, establish how pages and components should animate, or plan a motion-package overhaul before implementation; do not use to diagnose implemented defects, configure TurbulenceJS directly, review one bounded change, or execute an approved policy.

## Prerequisites

Start with the project, evidence, approval state, and same-slug artifacts named by the request. Required package relationships are none; optional skills are not assumed to be installed.

## Authority and safety

It may inspect project and external evidence and write only its skill-scoped work artifacts. It does not edit project source or mutate external systems. The canonical skill instructions remain authoritative when a request has narrower limits.
